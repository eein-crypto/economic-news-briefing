# 경제 뉴스 브리핑 앱

매일 아침 8시에 국내외 경제 뉴스를 자동으로 수집하여 초등학생도 이해하기 쉬운 수준으로 요약하고 투자 리포트를 제공하는 웹 앱입니다.

## 주요 기능

- 📰 **자동 뉴스 수집**: RSS 피드 + 웹 크롤링으로 매일 아침 8시에 자동 수집
- 📖 **쉬운 설명**: 초등학생도 이해할 수 있는 수준의 요약
- 📊 **투자 리포트**: 경제 분석 및 투자 전략 제공
- ✅ **예측 검증**: 투자 예측의 정확도를 추적
- 📱 **PWA**: 스마트폰에 설치 가능
- 🔔 **알림**: 브리핑 시간 설정 가능

## 뉴스 소스

- 한국경제
- 네이버 뉴스
- 다음 뉴스
- 로이터
- AP통신

## 기술 스택

- **프론트엔드**: React 19 + Tailwind CSS
- **자동화**: GitHub Actions (매일 8시 실행)
- **배포**: Vercel
- **저장소**: GitHub

## 설치 및 사용

### 웹에서 사용
1. 배포된 URL 방문
2. 뉴스 브리핑 확인
3. 설정에서 알림 시간 설정

### 스마트폰 설치 (PWA)

#### iOS
1. Safari에서 앱 열기
2. 공유 버튼 클릭
3. "홈 화면에 추가" 선택

#### Android
1. Chrome에서 앱 열기
2. 메뉴 (⋮) 클릭
3. "앱 설치" 또는 "홈 화면에 추가" 선택

## 개발

### 로컬 개발
```bash
pnpm install
pnpm run dev
```

### 빌드
```bash
pnpm run build
```

### 뉴스 수집 (수동)
```bash
pnpm run fetch-news
```

## 자동화

GitHub Actions를 사용하여 매일 아침 8시(KST)에 자동으로:
1. 뉴스 수집
2. 요약 생성
3. 데이터 저장
4. 웹 앱 업데이트
